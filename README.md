# Machine Learning Datasets Projects

This repository contains three beginner-friendly Machine Learning projects developed using Python, Pandas, Scikit-learn, and Matplotlib.

## 📌 Projects Included

### 1. California Housing Dataset
A Linear Regression model is used to predict median house values based on housing-related features.

**Topics covered:**
- Data Collection
- Data Cleaning
- Data Preprocessing
- Feature Selection
- Linear Regression
- Model Training
- Model Evaluation
- Mean Absolute Error (MAE)
- Prediction

### 2. Netflix Recommendation
A content-based recommendation approach is demonstrated using Netflix data.

**Topics covered:**
- Data Collection
- Data Cleaning
- Data Preprocessing
- Feature Engineering
- TF-IDF
- Cosine Similarity
- Recommendation
- Hyperparameter Tuning

### 3. Iris Dataset
A Decision Tree classification model is used to predict the species of Iris flowers.

**Topics covered:**
- Data Collection
- Data Cleaning
- Data Preprocessing
- Feature Selection
- Decision Tree Classification
- Model Training
- Model Evaluation
- Accuracy
- Confusion Matrix
- Hyperparameter Tuning

## 🛠️ Technologies Used

## 🎯 Objective

The objective of these projects is to understand and demonstrate the basic Machine Learning workflow, from data collection and preprocessing to model training, evaluation, and prediction.
